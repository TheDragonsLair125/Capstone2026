# Capstone2026
My Capstone Project. Basic C++ like interpreter. 

Welcome to the C++ Lite compiler!

To run simply download than extract to folder of use.
To run a file simply put the folder than type the name of 
the file when starting up the program!

Currently this interpeter / C++ Lite can do the following
1. Ints, Strings, and Bools
2. Math and logical arthimatic
3. If, Else If, and Else Statements
4. While Loops
5. User input and output through CIN and COUT
